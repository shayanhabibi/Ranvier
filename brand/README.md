# Ranvier brand assets v1.0

See ranvier-brand-spec.md for identity rules and usage.

- logos/: F2 icon, wordmark lockup without tagline, optional tagline lockup; dark, light, mono. Gradient lockups are for large feature use.
- states/: ready, pending, retained, fallback, failed, recovered; dark, light, mono.
- tokens/: CSS and JSON for dark and light themes.

The default horizontal logo is logos/f2-arrival-pulse-wordmark-dark.svg or its light variant. The file named f2-arrival-pulse-logo includes a provisional tagline. Keep semantic state marks flat.

The outlined wordmark uses DejaVu Sans. The font notice is included in FONT-LICENSE.txt. Before a public release review mark/name/tagline clearance and font licensing.
